# 0001: ADRs verwenden

- Status: angenommen
- Datum: 2026-11-17

## Kontext

Die Website wird von einem kleinen Vereinsteam über Jahre betreut. Wer später
dazukommt, soll nachvollziehen können, warum etwas so gebaut ist.

## Entscheidung

Grundlegende Entscheidungen werden als kurze Markdown-ADRs in
`docs/decisions/` festgehalten (Kontext – Entscheidung – Konsequenzen).

## Konsequenzen

Wenig Aufwand pro Entscheidung, Doku liegt versioniert beim Code.
Änderungen an Entscheidungen erfordern einen neuen ADR.
